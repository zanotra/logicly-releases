# Contribute to Logicly

This repository holds Logicly's public release assets, documentation and feedback.
Application development takes place in a separate repository.

## Bugs, ideas and questions

See [SUPPORT.md](SUPPORT.md) for the right place to ask a question or report a problem.
Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

## Documentation changes

For a change to files in this repository:

1. Fork the repository and create a branch.
2. Make a focused change with generic examples and no customer data.
3. Check the Markdown preview, links and any commands you changed.
4. Open a pull request that explains the change and how you checked it.

For a correction to the [wiki](https://github.com/zanotra/logicly-releases/wiki), open a documentation issue
with the page URL and proposed correction. The wiki has a separate Git history.

Do not commit application binaries or installers. The release workflow publishes them as GitHub release assets.
