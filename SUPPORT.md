# Get help with Logicly

## Install and use Logicly

- [Download the latest release](https://github.com/zanotra/logicly-releases/releases/latest).
- [Install and update](https://github.com/zanotra/logicly-releases/wiki/Install-and-update).
- [Open your first project](https://github.com/zanotra/logicly-releases/wiki/First-project).
- [Read the user guide](https://github.com/zanotra/logicly-releases/wiki).

## Ask a question

Use [Discussions](https://github.com/zanotra/logicly-releases/discussions) for setup questions,
workflow advice and ideas that need discussion.

## Report a bug or request a feature

Search [existing issues](https://github.com/zanotra/logicly-releases/issues) first.
If no issue matches, [create an issue](https://github.com/zanotra/logicly-releases/issues/new/choose)
with the appropriate form. Include the Logicly version, operating system and steps that reproduce a bug.
For a feature request, explain the task you need to complete and what blocks it.

Issues and discussions are public. Use a small, generic example instead of a customer project.
Remove customer names, credentials, tokens and private network details from logs and screenshots before you upload them.

## Report a security problem

Follow the [security policy](SECURITY.md) to report vulnerabilities privately.
Do not include security details in a public issue or discussion.
